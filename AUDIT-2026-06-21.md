# TokenLens release audit — 2026-06-21

## Verdict

The product has a viable narrow wedge, but not because cost attribution is
unique. Helicone now includes user analytics, custom properties and alerts;
Langfuse includes cost metrics, monitors and a broad free tier. TokenLens is
defensible as the simpler **metadata-only** option: no proxy, no prompt or
response storage, and a dashboard organized directly around business cost
dimensions.

Primary sources checked:

- Helicone pricing/features: https://www.helicone.ai/pricing
- Langfuse pricing/features: https://langfuse.com/pricing
- OpenAI standard API pricing: https://platform.openai.com/docs/pricing
- Anthropic model pricing: https://platform.claude.com/docs/en/about-claude/pricing

## Release blockers found and fixed

- Live Supabase service-role key was invalid (401); replaced and verified 200.
- Date-range migration 0006 had not been applied; 0006-0008 now live.
- Ingest accepted oversized/unbounded data; payload, batch and field validation added.
- User webhooks could target private/metadata IPs; HTTPS, DNS/IP and redirect guards added.
- Alert email HTML was not escaped.
- Failed alert deliveries were incorrectly marked as triggered.
- Payment logging and Pro grants were not atomic; moved into one restricted DB function.
- TypeScript HTTP sink silently dropped events on HTTP 4xx/5xx; it now re-buffers/retries.
- Web lint failed and no CI/dependency automation existed.
- SDK and SEO pricing lacked current GPT-5.5/5.4 and Claude 4.8/4.6/4.5 models.
- Public copy claimed unimplemented unlimited events/retention; removed.
- GitHub/package placeholders and one wrong footer URL were fixed.

## Verified

- Web: lint, 5 security/validation tests, production build (46 routes).
- TypeScript SDK: 4 tests, clean npm tarball, zero dependency vulnerabilities.
- Python SDK: 12 tests, wheel/sdist build, Twine checks.
- Clean CI build succeeds without `.env.local`.
- Live app active with zero service restarts; Supabase admin REST returns 200.
- npm and PyPI package names `tokenlens-sdk` are available as of this audit.

## Residual risks / account blockers

- npm and PyPI publishing still require registry login; no credentials are configured.
- Resend and payment-provider credentials are not configured, so those channels remain off.
- Latest stable Next.js 16.2.9 embeds a PostCSS version with a moderate advisory. There is
  no non-breaking stable Next upgrade yet; CI blocks high/critical advisories and
  Dependabot will surface the stable fix.
- SDK pricing uses standard non-cached rates. Cached, batch, flex, priority, regional and
  long-context variants need explicit pricing overrides until a richer usage schema lands.
- No public launch posts should be sent before dogfood data and screenshots exist.
